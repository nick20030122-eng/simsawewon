# AI 심사위원 — 코드 기획서

## 1. 배경 — 어떤 문제를 푸는가

기관·기업의 바이브 코딩 교육 과제를 사람 심사위원이 채점할 때 두 가지 병목이 있습니다.

- **분량**: 한 기수에 수십 건이 제출되고, 각 건마다 기획서와 코드를 대조해야 합니다.
  제출물 하나를 제대로 읽는 데 20~30분이 걸립니다.
- **일관성**: 앞에 본 제출물이 뒤 채점에 영향을 주고, 심사위원마다 기준이 달라
  같은 수준의 제출물이 다른 점수를 받습니다.

이 도구는 사람 심사를 대체하지 않습니다. **1차 선별과 기준선 제시**를 맡아
심사위원이 애매한 건에 시간을 쓸 수 있게 합니다.

## 2. 무엇을 만드는가

공개 GitHub 레포 주소 하나를 받아, 레포에서 기획서와 코드를 자동 수집해
2개 분야 6개 항목을 채점하고 심사 결과서를 발급하는 웹 앱입니다.

### 심사 트랙

제1분야는 트랙마다 기준이 다르고, 제2분야는 두 트랙 공통입니다.

| 트랙 | 제1분야 | 세부 항목 |
|------|---------|-----------|
| 기관용 | 공공기관 적합성 | 페인포인트 명확성 / 해결 방향 적절성 / 공공 현장 적용 가능성 |
| 기업용 | 사업 타당성 | 문제·비용 구체성 / 자체 구축 정당성 / 도입·운영 현실성 |

| 공통 | 제2분야 | 세부 항목 |
|------|---------|-----------|
| 두 트랙 | 의도 구현도 | 핵심 요구사항 구현 / 성공 기준 충족 / 기획 의도 일치 |

분야 점수는 세부 3항목의 평균, 종합 점수는 2개 분야의 평균입니다.
두 트랙은 기준이 다르므로 점수를 서로 비교하지 않습니다.

## 3. 핵심 기능

| # | 기능 | 성공 기준 |
|---|------|-----------|
| 1 | 레포 자동 수집 | GitHub 공개 레포에서 기획서(`PLAN.md`·`기획서.md`)와 소스 파일을 언어 무관하게 최대 25개 수집 |
| 2 | 트랙 선택 | 접수 화면에서 기관용·기업용 중 선택. 미지정 시 기관용 |
| 3 | 입력 적격성 검증 | 무의미한 입력·주제 불일치를 분야별로 판정해 해당 분야만 0점 처리하고 사유를 남김 |
| 4 | 앙상블 채점 | 항목마다 독립적으로 3회 채점해 중앙값을 최종 점수로 기록 |
| 5 | 판정 불안정 표시 | 3회 간 점수 폭이 임계값(15)을 넘으면 표식을 붙여 사람 확인을 유도 |
| 6 | 모델 이중화 | 채점 모델 호출이 실패하면 폴백 모델로 자동 전환 |
| 7 | 진행 스트리밍 | 수집→검증→채점→집계→총평 5단계를 NDJSON으로 실시간 전송 |
| 8 | 심사 결과서 | 종합·분야 점수, 세부 채점표, 잘한 점, 감점 요인(최대 5개), 총평 |
| 9 | 음성 브리핑 | 결과를 2구간 대본으로 만들어 TTS 재생. 실패해도 점수는 유효 |

## 4. 성공 기준

- 같은 제출물을 다시 채점했을 때 종합 점수 표준편차가 **3점 이내**
- 제출부터 결과서까지 **2분 이내**
- 기획서가 없거나 코드가 없는 레포는 오류가 아니라 **사유가 적힌 0점 결과서**로 처리
- 감점 요인에 코드 스타일·네이밍·제출 방식 지적이 **한 건도** 섞이지 않을 것

## 5. UI 요구

- 홈: 트랙 소개와 채점 방식
- 심사 접수: 트랙 선택 + 레포 주소 입력 + 진행 단계 표시
- 채점 기준: 트랙별 제1분야와 공통 제2분야의 세부 항목 설명
- 결과서: 공문서 형식. 관인 스탬프와 종합 점수를 시그니처 요소로

## 6. 예외 처리

| 상황 | 기대 동작 |
|------|-----------|
| 비공개 레포·잘못된 URL | 원인을 구분한 안내 메시지 |
| GitHub API 한도 초과 | 대기 시간과 토큰 등록 안내 |
| 기획서 파일 없음 | 두 분야 부적격, 전 항목 0점 + 사유 명시 |
| 소스 파일 없음 | 진입점 포함 여부를 안내하고 심사 중단 |
| 총평 생성 실패 | 기본 총평으로 대체, 점수는 정상 산출 |
| 음성 합성 실패 | 대본 텍스트만 표시 |

## 7. 범위 밖

- 코드 실행·테스트 수행 (제출된 글만 읽음)
- Pass/Fail 판정 (점수만 제공)
- 코드 스타일·리팩토링 지적
- 비공개 레포, GitHub 외 호스팅

## 8. 기술

- Next.js App Router (TypeScript), Tailwind CSS
- OpenAI structured output (zod 스키마), 앙상블 병렬 호출
- Vercel 배포, GitHub API로 레포 수집
