# 민원 처리 지연 현황 대시보드 기획서

## 1. 배경 — 어떤 행정 업무가 왜 비효율적인가

○○구청 민원지원과는 매월 초 지난달 민원 처리 실적을 집계해 부구청장 보고와
정보공개 게시판 갱신에 씁니다. 지금은 새올행정시스템에서 민원 접수 대장을 CSV로
내려받아 담당자가 엑셀에서 수기로 처리합니다.

- 집계 대상: 월평균 민원 약 1,400건 (부서 11개, 민원 유형 23종)
- 소요 시간: 담당자 1명이 **월 6~8시간** (처리일수 계산 + 기한 초과 건 대조)
- 가장 큰 문제: **법정 처리기한 초과 건을 사후에야 발견**합니다. 유형마다 기한이
  달라(즉시 처리 3일 ~ 일반 민원 14일) 수기로는 월말에만 확인이 가능하고,
  그 시점에는 이미 초과가 확정된 뒤입니다.
- 결과: 월평균 20~30건이 기한을 넘긴 뒤 파악되고, 그중 일부는 민원인 재접수나
  국민신문고 이의제기로 이어져 담당 부서가 소명 자료를 다시 준비합니다.

담당자가 바뀔 때마다 엑셀 수식과 기한 기준을 다시 익혀야 해 업무 연속성도 끊깁니다.

## 2. 만들 것

민원 접수 대장 CSV를 올리면 유형별 법정 처리기한과 대조해 **지연 건과 지연 임박 건**을
찾아주고, 부서별·유형별 처리 현황을 보여주는 웹 대시보드.

### 핵심 기능

| # | 기능 | 성공 기준 |
|---|------|-----------|
| 1 | CSV 업로드 | 새올 대장 형식 CSV 1개 업로드. UTF-8·CP949 모두 인식 |
| 2 | 처리일수 계산 | 접수일과 처리완료일의 차이를 일수로 산출. 미처리 건은 기준일까지로 계산 |
| 3 | 기한 초과 판정 | 민원 유형별 법정 처리기한 표와 대조해 초과/임박(잔여 2일 이내)/정상 분류 |
| 4 | 부서별 집계 | 부서마다 처리 건수·평균 처리일수·초과 건수·초과율 표시 |
| 5 | 지연 건 목록 | 초과·임박 건을 잔여일 오름차순으로 표시. **민원인 성명·연락처 컬럼은 제외** |
| 6 | 집계 결과 내려받기 | 부서별 집계와 지연 건 목록을 CSV로 저장해 보고서에 첨부 |

### 성공 기준

- 1,400건 CSV를 올렸을 때 **10초 이내** 집계 완료
- 기한 초과 판정 결과가 담당자 수기 집계와 **오차 3% 이내**
- 담당자 월 작업 시간 6~8시간 → **월 30분 이내**
- 월말이 아니라 **주중 아무 때나** 올려 지연 임박 건을 미리 확인 가능

### 예외 처리

| 상황 | 기대 동작 |
|------|-----------|
| 필수 컬럼(접수일·민원유형·처리부서) 누락 | 누락된 컬럼명을 지목해 안내, 집계 중단 |
| 날짜 형식이 섞여 있음 | 인식 가능한 형식만 집계하고 제외 건수를 화면에 표시 |
| 기한 표에 없는 민원 유형 | 일반 민원 기준(14일)을 적용하고 해당 유형을 별도 안내 |
| 빈 파일·헤더만 있는 파일 | 안내 문구 표시 후 중단 |

## 3. 공공 현장 적용 전제

- **개인정보**: 민원인 성명·연락처·주소 컬럼은 읽더라도 화면과 내려받기에서 제외합니다.
  집계에 필요한 것은 접수일·유형·부서·처리일뿐입니다.
- **데이터 확보**: 담당자가 기존 권한으로 이미 매월 내려받는 CSV를 그대로 씁니다.
  새올행정시스템과의 직접 연동은 하지 않으므로 별도 정보시스템 승인 절차가 없습니다.
- **배포 위치**: 업무망 내부 서버에 단일 프로세스로 기동합니다. 외부망 전송이 없어
  망 분리 정책에 저촉되지 않습니다.
- **담당 조직**: 민원지원과 통계 담당 1명이 운영합니다. 법정 기한이 개정되면
  상단 기한 표만 수정하면 되도록 분리했습니다.
- **투명성**: 부서별 초과율을 같은 기준으로 산출해, 정보공개 게시판에 올리는 수치와
  내부 보고 수치가 어긋나지 않게 합니다.

## 4. 범위 밖

- 새올행정시스템 실시간 연동 (수동 CSV 업로드로 시작)
- 민원인 개인 단위 조회·알림 발송
- 공휴일·토요일 제외 영업일 계산 (1차는 역일 기준)
- 타 기관 데이터 비교
